# Security Policy

## Supported Versions
Only the latest release on the `main` branch receives active security updates and vulnerability patches.

## Reporting a Vulnerability
If you discover a security vulnerability within SOUQ, please DO NOT open a public GitHub issue.
Instead, send an encrypted security advisory to `security@souq-ethiopia.example.com` or create a private GitHub Security Advisory.
Please include:
1. Detailed description of the vulnerability and attack vector.
2. Steps or proof-of-concept scripts to reproduce.
3. Impact assessment on user data, payments, or availability.

We acknowledge receipt within 24 hours and commit to a fix within 7 days.
